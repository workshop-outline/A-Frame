# Starter Pack – A-Frame 01

This starter pack is for the Week 2 introduction to A-Frame.

Open `index.html` in VS Code and run it using Live Server.

The starter scene contains:

- `<a-scene>` — the 3D environment
- `<a-sky>` — the surrounding background
- `<a-plane>` — a simple ground surface
- `<a-box>` — a cube inside the space
- a second wireframe box — a simple outline to make the cube edges easier to recognise

Use your mouse to look around the scene.

Try making only a few simple changes:

- change the sky colour;
- change the ground colour;
- change the cube colour;
- change the cube position.

Keep the `assets` folder for any media you may want to add later.
