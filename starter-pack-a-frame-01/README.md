# Starter Pack – A-Frame 01

This starter pack is for the Week 2 introduction to A-Frame.

Open `index.html` in VS Code and run it using Live Server.

Focus on three basic elements:

- `<a-scene>` — creates the 3D environment
- `<a-sky>` — creates the surrounding background
- `<a-box>` — places a simple 3D object inside the environment

Try making only a few simple changes:

- change the sky colour;
- change the box colour;
- change the box position.

Keep the `assets` folder for any media you may want to add later.
